English personal-assistant setup for Apple Silicon Macs, styled after Aplaud's Pixel OS.

- Native installer and Dock launcher.
- Guided ChatGPT Plus, Gmail, iCloud, WhatsApp and Calendar setup.
- Local conversations, a daily brief and an approval queue for new appointments.
- Optional Qwen local model download through the app.
- Signed update checks, idle installation and recovery if an update cannot start.

Download **Ray-Mac-Installer.zip**. The **Ray.resources.zip** file is for the automatic updater.

Requires Apple Silicon and macOS 13.5+. This is an early build: the recipient's accounts, real Calendar writes and M1 Max model performance still need validation. The installer is ad-hoc signed, not Apple-notarized; macOS may require Open Anyway with Gatekeeper kept enabled. WhatsApp uses an unofficial, read-only connector. The optional local model is approximately 23 GB and is downloaded separately.

No connected accounts or personal data are bundled. Herdr remote access is a later setup step and is not enabled in this release.
