# Ray installer releases

Mac installer downloads for Ray, a personal assistant for Apple Silicon.

Download the current installer from [Releases](https://github.com/roluron/ray-assistant/releases). Unzip it, open **Install Ray.app**, and follow the setup steps.

Requires Apple Silicon and macOS 13.5 or newer. ChatGPT, email, WhatsApp and Calendar connections are configured on the recipient's Mac. No connected accounts or personal data are included in these downloads.

This is an early build. Account integration and performance on the recipient's Mac still require validation. The app is not Apple-notarized, so macOS may request explicit approval on first open. Keep Gatekeeper enabled.

This repository contains installer releases and a signed update feed. It does not publish a separate application source repository. Bundled software remains inspectable and its third-party notices are included in the kit. WhatsApp MCP is unmodified MPL-2.0 software; its corresponding source is available [upstream](https://github.com/StephanMeijer/whatsapp-mcp/tree/cae6b92eb3d750957beebf4b7d7f64c8033f9097).
